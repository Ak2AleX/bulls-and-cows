# DESIGN

## Структуры данных и алгоритмы

**Алфавит.** Все цифры лежат в одной константе `DIGITS = '0123456789abcdef'`
(`digits.ts`), а алфавит системы это её префикс `DIGITS.slice(0, base)`.

**Состояние и история.** `GameState` (`state.ts`) содержит `readonly`-поля:
настройки, секрет, историю, статус, время начала и окончания. История это
массив `{ guess, bulls, cows }`: он хранит порядок попыток, а новая запись
добавляется через `[...history, entry]`, поэтому старое состояние не
меняется. Повтор, неверная попытка и попытка после победы возвращают тот же
объект.

**evaluateGuess** (`evaluate.ts`). Строки приводятся к нижнему регистру и
разбиваются на массивы символов. Первый `filter` считает быков (цифра совпала
по значению и позиции), второй коров (цифра есть в секрете, но на другой
позиции). Цифры секрета уникальны, поэтому двойного счёта нет.

**countPossibleSecrets** (`count.ts`). Это число перестановок
P(base, length) = base! / (base − length)!. Первую цифру можно выбрать `base`
способами, дальше задача сводится к `(length − 1, base − 1)`. Первая цифра не
ограничена, секрет может начинаться с нуля. Результат мемоизируется через
`memoize` (`memoize.ts`): кэш `Map` спрятан в замыкании и меняется только
внутри обёртки.

**Рекорды.** Отдельный список на каждую комбинацию длины и системы, ключ строит
`leaderboardKey` (`leaderboard.ts`).

## Сложность

| Функция              | Время                   | Обоснование                                                                   |
| -------------------- | ----------------------- | ----------------------------------------------------------------------------- |
| generateSecret       | O(length · base)        | `length` шагов рекурсии, на каждом `filter` по пулу до `base` элементов       |
| evaluateGuess        | O(length²)              | `includes` внутри `filter`; со `Set` секрета было бы O(length), но length ≤ 6 |
| isValidGuess         | O(length)               | один проход для `every` и один для построения `Set`                           |
| countPossibleSecrets | O(length), из кэша O(1) | `length` умножений в рекурсии, повторный вызов берёт результат из `Map`       |
| createDigitValidator | O(1)                    | алфавит ограничен 16 символами                                                |

## Принципы чистого кода

- **Нет магических значений.** `DIGITS` (`digits.ts`), `LENGTHS`, `BASES`,
  `TOP_N` (`settings.ts`).
- **Говорящие имена.** `secretChars`, `guessChars` (`evaluate.ts`),
  `byAttemptsThenTime` (`leaderboard.ts`).
- **Чистые функции.** `random` и время `now` передаются параметрами
  (`generateSecret` в `secret.ts`, `addGuess` в `state.ts`).
- **Побочные эффекты изолированы.** `localStorage` только в `storage.ts`,
  DOM только в `dom.ts`, `src/logic/` не знает про браузер.
- **Без `innerHTML`.** `h()` (`dom.ts`) создаёт элементы через `createElement`.
