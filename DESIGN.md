## Структуры данных и алгоритмы

Все цифры хранятся в одной константе DIGITS = '0123456789abcdef'
за счёт чего сразу можно использовать её в нескольких форматах

### evaluateGuess

Функция сравнивает попытку с секретом. Обе строки приводятся к нижнему регистру
и разбиваются на массивы символов. Затем два прохода filter

### Мемоизация

memoize это функция высшего порядка. Кэш спрятан в замыкании и изменяется только внутри неё

### countPossibleSecrets

Число секретов равно числу перестановок без повторений
P(base, length) = base! / (base − length)!. Первая цифра выбирается base
способами, дальше задача сводится к (length − 1, base − 1). Ограничений на
первую цифру нет, поэтому секрет может начинаться с нуля. Результат
мемоизируется через memoize (src/logic/count.ts): функция вызывается при
каждом открытии настроек, пересчитывать заново не нужно.

## Сложность

| createDigitValidator | O(1), потому что алфавит ограничен 16 символами | slice и includes по строке длиной не больше 16 |
| isValidGuess | O(length) | один проход для ever` и один для построения Set |
| evaluateGuess | O(length²) | includes внутри filter сам проходит по секрету; с Set секрета было бы O(length), но при длине не больше 6 разницы нет |
| generateSecret | O(length · base) | length шагов рекурсии, на каждом filter проходит по пулу из не более чем base элементов |
| countPossibleSecrets | O(length) при первом вызове, O(1) из кэша | length шагов, каждый выполняет одно умножение, повторный вызов находит результат в кэше |
